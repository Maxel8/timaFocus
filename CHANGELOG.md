# Changelog

All notable changes to timaFocus are documented here.


## [Unreleased]

## [0.3.0] - 2026-11-06

### Added

- Added dynamic browser tab title
- Added the possebility to install timaFocus as a Progressive Web App (PWA)

### Changed

- Improved timer accuracy (timestamp-based time calculation)


## [0.2.1] - 2026-11-05

### Added

- Added Open Graph metadata for link previews when sharing the website
- Added favicon for browsers
- Added Apple Touch Icon for iOS home screen
- Added `robots.txt` to guide search engine crawlers

## [0.2.0] - 2026-11-05

### Added
- Customizable timer durations
- Visual feedback when the timer finishes

### Changed
- Improved timer controls
- Refined user interface


## [0.1.0] - 2026-11-03

### Added
- Basic countdown timer (30s)
- Start, pause and reset functionality
